# Portfolio - Sérgio Cerillo

Portfolio pessoal de UX/UI Design e Front-End Development.

## 🚀 Tecnologias

- HTML5 semântico
- CSS3 (Custom Properties, Grid, Flexbox)
- JavaScript vanilla (ES6+)
- Design responsivo
- Animações e transições suaves
- Acessibilidade (WCAG)

## 📦 Estrutura

```
portfolio/
├── index.html          # Página principal (inclui Projetos e Escrita)
├── style.css          # Estilos principais
├── main.css           # Estilos alternativos
├── script.js          # Interatividade
├── sitemap.xml        # Sitemap para SEO
├── robots.txt         # Instruções para crawlers
├── .htaccess          # Configurações Apache
└── imgs/              # Imagens e assets
    ├── favicon.ico
    ├── logo.svg
    ├── og-image.jpg   # 1200x630px para Open Graph
    └── projects/      # Screenshots dos projetos
```

## 🎨 Funcionalidades

- ✅ Navegação suave entre seções
- ✅ Animações de scroll reveal
- ✅ Filtro de projetos por categoria
- ✅ Barras de progresso de habilidades

- ✅ SEO otimizado

- ✅ Acessível (ARIA labels, skip links)
