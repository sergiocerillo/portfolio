01 · Contexto

Encontrar um carro também é organizar informação.

A camada de front-end precisava suportar uma grande quantidade de veículos, diferentes critérios de busca e uma leitura rápida em desktop e mobile.

O projeto foi desenvolvido sem framework JavaScript, o que exigiu atenção especial à estrutura, performance e comportamento dos componentes.

02 · Solução

Grid, filtros e microinterações trabalhando juntos.

01

Grid de estoque

Cards organizados para facilitar a comparação entre veículos.

02

Filtros de busca

Critérios de seleção para reduzir o esforço de encontrar uma opção.

03

Performance

Carregamento e comportamento pensados para a navegação real.

04

Microinterações

Feedback visual para orientar ações e estados da interface.

03 · Resultado

HTML e CSS também podem sustentar experiências complexas.

O projeto reforçou como uma base front-end bem estruturada pode entregar clareza, velocidade e consistência sem depender de um framework.
